# مرتب‌ساز PDF سالانه — نسخهٔ پایتون داخل اندروید

این پروژه یک نمونهٔ مستقل Android Studio است که موتور پایتون را با Chaquopy داخل APK قرار می‌دهد. فایل مرجع `class_list_fast_FINAL_REFERENCE.py` فقط برای نگهداری و مقایسه کپی شده و تغییر داده نشده است.

## ساخت APK
1. پروژه را در Android Studio باز کنید.
2. با اینترنت، اجازه دهید Gradle و Chaquopy وابستگی‌ها را دریافت کنند.
3. از منوی Build گزینهٔ Build APK(s) را اجرا کنید.

## نکات مهم
- APK از طریق انتخاب‌گر رسمی اندروید چند PDF را می‌گیرد؛ فایل‌های اصلی را تغییر نمی‌دهد.
- خروجی در پوشهٔ خصوصی خارجی برنامه، زیر `Android/data/com.example.pdfsorter/files/مرتب‌ساز PDF/سال <سال>/` ذخیره می‌شود.
- موتور از `pypdf` و استخراج متن layout استفاده می‌کند. این استخراج با `pdftotext -layout` تضمین‌شده یکسان نیست؛ پیش از توزیع به همکاران، خروجی چند PDF واقعی باید با نسخهٔ مرجع مقایسه شود.
- این مخزن سورس آمادهٔ ساخت است، نه APK از پیش ساخته و آزمایش‌شده.


## ساخت خودکار APK با GitHub Actions

1. یک مخزن جدید در GitHub بسازید.
2. محتویات این پوشه را در ریشهٔ مخزن بارگذاری کنید؛ فایل `gradlew` و پوشهٔ `.github/workflows` هم باید بارگذاری شوند.
3. در صفحهٔ مخزن، زبانهٔ **Actions** را باز کنید و اجرای **Build PDF Sorter APK** را انتخاب کنید؛ روی **Run workflow** بزنید.
4. پس از سبز شدن اجرا، در همان اجرای workflow پایین صفحه بخش **Artifacts**، فایل `PDFSorter-debug-APK` را دریافت کنید.
5. APK داخل آن را روی گوشی نصب کنید.

این workflow فقط سورس را می‌سازد؛ APK از پیش ساخته‌شده نیست. برای بارگذاری سورس لازم نیست کل پوشهٔ `.gradle` یا `build` را بفرستید. خروجی هنوز باید با PDFهای واقعی آزمایش شود.
